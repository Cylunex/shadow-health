# 每周有据复盘

明确上一完整星期的结束日期，调用 query_weekly_evidence(end)。
引用工具返回的本期/前期覆盖天数、均值、来源和差值，两个窗口必须互不重叠。
差值为空不能自行补算；来源改变、待重同步、权限撤销或记录不足时说明限制。
饮食记录覆盖不等于真实摄入完整，不能用热量差倒推漏记或自动改目标。

需要保存复盘时引导 Health → 健康助手 → 回顾上个完整星期。
最多提出一项可选的日常行动，用户主动采纳后在 UI 保存期限；不能替用户确认。
到期回看只能描述同期变化，不把变化归因于这项行动。不要默认保存整段对话为长期记忆。
