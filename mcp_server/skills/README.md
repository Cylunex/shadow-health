# Health MCP v2 的领域提示

此目录是外部 Agent 的领域提示，不是权限来源。部署时必须同时更新 MCP 工具清单和这些提示。
所有调用使用独立 Health 主体，禁止数据库直连、设备凭据回退、隐藏提交或删除。

- recorder.md：一餐草案、显式日期、稳定幂等键、用户审核。
- morning-briefing.md：用户询问时读取少量日常数据，不生成医疗/训练评分。
- weekly-review.md：独立窗口与证据，用户采纳后再去 UI 创建行动。
- analyst.md：最小授权查询，不取全库上下文。

本目录不创建任何定时任务；提醒默认关闭，须由用户在 Health 中开启。
